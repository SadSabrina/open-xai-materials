## Three repositories and what each one is for

These rules were adopted on 05.08.2026, and some of them have since been replaced. The rules in
force are in the file `Curriculum/Правила проекта.md` (Project rules) of open-xai-org, the course's
planning repository (checked on 28.10.2026); where a 05.08 rule below differs from them, this is marked in place. The
course content lives in three places, and mixing them up is costly: an edit made in the wrong
repository is lost at the next synchronization.

```
                 pulled → fixed → pushed back
   Stepik  ←──────────────────────────────────────────→  open-xai-materials-private
   (Russian, live)                                       (Russian, workshop)
                                                                  │
                                                                  │ agreed on
                                                                  │ and marked ready
                                                                  ↓
   open-xai-materials                                      open_xai_platform
   (notebooks, public)  ←── links ───                      (site: EN and RU)
```

### `related/open-xai-materials-private`: the workshop for Russian content

All work on the lesson texts happens here. The workflow is always the same:

1. **pulled**: a block is exported from Stepik (`stepik_scripts/export_content.py`, then
   `export_module.py`), and a read-only snapshot is saved to `stepik_snapshots/<date>/`;
2. **fixed**: proofreading, new lessons, restructuring, tasks, spoilers, images;
3. **agreed on**: the review and the decisions are recorded in `Curriculum/` of the open-xai-org
   repository;
4. **pushed back**: `push_module.py` sends the corrected content to Stepik; our scripts do not write
   to Sabrina's sections (the `protected` field in `modules.map.json`).

Everything stored here, except the snapshots in `stepik_snapshots/`, is **synchronized with
Stepik**. The 05.08 rule "there is no English here and there must not be" has been cancelled: the
English version of the course is primary, and the solved homework notebooks have their English
versions next to them (`*_solved_en.ipynb`).

Tasks that belong here: proofreading, formulas, block structure, redrawing images, and deleting and
reordering steps on Stepik.

### `related/open-xai-materials`: public notebooks

An open repository with homework assignments, tutorials and practice notebooks, holding only what
has been **checked and works**. **If a material is stored here, links to it from
both Stepik and the site lead here**, not to a personal Colab and not to Google Drive.

A notebook gets here once it has been run end to end, the numbers in the answer keys of the course's
auto-graded tasks have been checked against the cell outputs, the data is available, and the solutions
have been removed from it. The English versions sit next to the originals, with the `_en` suffix.

### `open_xai_platform`: the site

This repository publishes the course at [ai-interpretability.school](https://ai-interpretability.school) in English
and Russian. It holds the site content (`web/content/`), the platform, and the build and deployment
scripts.

The site may have more than Stepik, but never less: only new material is carried from Stepik to the
site, and nothing goes from the site to Stepik. What exists on Stepik is edited on Stepik, and the
edit reaches the site as new material; what exists only on the site (Track B and modules 13, 18,
22–24) is edited only on the site. The English version is primary: the Russian one may link to an
English image or notebook, the reverse is forbidden, and an English step links only to the
`*_en.ipynb` notebooks from this repository.

Tasks that belong here: carrying new material over from Stepik, editing steps that Stepik does not
have, translation, `check_translation.py`, module numbering on the site, layout, deployment.

The 05.08 rule "a block is not imported to the site until it has been proofread and agreed on in
Russian; Stepik first, then the site and English" has been replaced by the rules above.
